# memorization-game-MZ_APO
A memory-pattern game written in C as a university project on the MicroZed development board.

The goal is to correctly replicate the image shown to the user, which sounds easy but actually is not, because the user has to keep in mind position, shape, and color of all of the figures.

Full documentation (generated by Doxygen) and a user manual is available in the .zip file.
